# Roadmap

## MVP

- responsive web shell
- auth
- campus map
- feed
- create post
- campus location association
- optional image
- post detail
- profile
- delete own post
- production deployment

## Post-MVP — Likely Next

- edit own post
- report content
- comments
- reactions
- map filters
- better marker clustering
- profile polish
- improved moderation
- analytics around activation/retention

## Later Product Ideas

Only pursue if real users want them:
- Lost & Found
- campus events
- verified clubs/organizations
- notifications
- saved posts
- richer discovery
- school-specific utility features

## Validation Principle

The roadmap should be driven by student usage and feedback.

A feature requested repeatedly by real users should outrank technically interesting infrastructure.
