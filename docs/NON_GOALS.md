# Non-Goals

The following are intentionally outside the initial MVP unless the user explicitly changes scope.

## Product Non-Goals

- full anonymous social network
- direct messaging
- followers/following
- stories
- algorithmic recommendation feed
- marketplace
- Lost & Found system
- event ticketing
- class scheduling
- push notification system
- native iOS app
- native Android app
- advanced reputation system

## Engineering Non-Goals

- microservices
- Kubernetes
- Kafka
- Redis
- distributed caching
- custom identity provider
- elaborate backend-for-frontend layer
- GraphQL migration for its own sake
- complex domain-driven architecture
- premature performance optimization
- custom file storage infrastructure
- self-hosting Supabase for MVP
- infrastructure created only to look impressive on a resume

## Scope Rule

If a requested implementation introduces substantial complexity but does not improve the core student experience, stop and reconsider the simpler design.
