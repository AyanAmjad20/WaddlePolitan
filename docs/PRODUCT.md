# Product Overview

## What is WaddlePolitan?

WaddlePolitan is a campus activity and discovery website for Toronto Metropolitan University students.

The central experience is a **live, interactive TMU campus map** connected to a student activity feed. Students can see recent posts tied to places around campus and contribute their own observations, alerts, sightings, or general campus updates.

The intended feeling is closer to a lightweight campus pulse than a full social network.

## Product Goals

The MVP should:

- make the TMU campus feel more alive and connected
- let students quickly see what is happening around them
- encourage low-friction student participation
- work naturally from a phone browser
- still feel polished on a laptop
- be small enough to build, ship, and iterate quickly
- establish a foundation for future campus-specific features

## Target User

Primary:
- current TMU students on or around campus

Typical use cases:
- checking what is happening before or between classes
- seeing recent activity near a building
- sharing something interesting, useful, funny, or noteworthy
- browsing the feed without opening the map
- opening a map marker to view its associated post

## Product Personality

WaddlePolitan should feel:
- student-built
- friendly
- modern
- local to TMU
- playful without being childish
- useful before being feature-heavy

It should not feel:
- corporate
- like a LinkedIn clone
- like a generic city social app
- like an anonymous chaos board
- overloaded with features

## Core Surfaces

### Landing Page

The public landing page should introduce the product and visually emphasize the interactive campus map.

Expected sections:
- hero / value proposition
- interactive or illustrative campus map preview
- Learn More
- How It Works
- For Students
- Contact

### Explore / Map

Primary discovery surface.

Users should be able to:
- view TMU campus
- see recent post markers
- click/tap markers
- inspect a post preview
- move between map and post detail
- create a post from a clear CTA

### Feed

A recent activity feed showing campus posts.

The feed should be useful independently of the map.

### Create

A low-friction post creation flow:
- message/body
- category/type if used
- campus location
- optional image
- submit

### Profile

Basic profile and the user's own posts.

Do not turn profile into a complex social graph for MVP.

## Success Criteria

Early success is not millions of users.

The MVP is successful if:
- students understand the concept immediately
- posting works reliably
- map + feed are pleasant to browse
- mobile experience is strong
- a small group of students returns and contributes
- the app is stable enough to share in student communities

An early release has already been discussed in the context of sharing with 50+ students, with a small recurring user base. Treat real usage as more important than artificial complexity.
